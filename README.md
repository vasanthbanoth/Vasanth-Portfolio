# Vasanth Banoth — Portfolio

Personal site for my work as an AI & Software Engineer.

**Live:** [vasanthdev.in](https://vasanthdev.in)

Built with React + Vite, deployed on GitHub Pages behind Cloudflare.

## What’s on it

- Experience (AirDawg Labs, Xelron AI, IIIT-Kota, and earlier internships)
- Projects and skills
- Resume download
- Contact

## Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the build:

```bash
npm run preview
```

## Deploy

Pushes to `main` are published to the `gh-pages` branch (GitHub Pages). Domain: `vasanthdev.in`.

```bash
npm run build
npx gh-pages -d dist
```
